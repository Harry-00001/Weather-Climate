🌦️ Weather App (Python Tkinter)
A simple and user-friendly Weather App built using Python and Tkinter.
This application allows users to check real-time weather details of any city through a clean graphical interface.


Python

Tkinter (GUI)

Requests (API integration)

Python-dotenv (for secure API handling)


📌 How It Works
 user enters a city name, and the app sends a request to a weather API.
It then processes the response and displays important weather details like temperature, humidity, and conditions in the interface.

🔐 API Security

The API key is stored securely using a .env file and is not exposed in the source code.
